# DESIGN.md — FORM 08 (가상 프라이빗 필라테스 스튜디오)

방향: **갤러리 벽.** 차가운 석고색 바탕, 얇은 명조 제목, 넓은 여백, 사진 한 장씩 걸어두듯 배치.
가장 눈에 띄는 요소는 홈 첫 화면의 큰 숫자 "08" 하나. 나머지는 조용하게.

값은 `assets/style.css`의 `:root` 변수에 있다. 페이지에서는 변수 이름만 쓴다.

## 색

| 토큰 | 값 | 역할 |
|---|---|---|
| `--plaster` | `#EEEEEA` | 기본 배경 (석고) |
| `--plaster-deep` | `#E2E1DB` | 큰 숫자 08, 사진 자리 |
| `--paper` | `#F8F8F5` | 버튼 위 글씨, 밝은 면 |
| `--ink` | `#1D1E1B` | 글씨, 기본 버튼 |
| `--stone` | `#67665F` | 보조 글씨 (대비 5.2:1) |
| `--line` | `#D6D5CF` | 구분선 |
| `--oak` | `#A88A64` | 선택된 메뉴 밑줄, 단계 숫자, "가장 많이 선택". 본문 글씨로 쓰지 않음 |
| 스프링 색 | 빨강 `#B5574B` · 파랑 `#4F6F95` · 노랑 `#C9A64A` | 수업 강도 표시 전용 (리포머 스프링 색) |

## 글씨

- 로고와 숫자: Italiana
- 제목: Hahmlet 200 (아주 얇은 명조)
- 본문: IBM Plex Sans KR 300
- 대문자 라벨, `→` 붙은 버튼, "A · B · C" 식 나열은 쓰지 않는다.

## 모양

- 모서리는 모두 직각 (radius 0). 그림자 없음.
- 버튼: 검은 사각 버튼(기본), 테두리 버튼(보조), 밑줄 링크(조용한 동작).
- 정보는 카드 대신 가는 선으로 나눈 목록으로 보여준다.

## 움직임

- 사진: 화면에 들어올 때 아래에서 위로 커튼 걷히듯 드러남 (한 종류만).
- 홈의 "08": 스크롤에 따라 천천히 이동.
- 사용자 동작에 반응하는 움직임: 탭 밑줄, 강사 정보 펼침, 메뉴 시트, 페이지 전환 페이드.
- `prefers-reduced-motion`이면 모두 끈다.

## 사진

- 톤: 오전 자연광, 흰 석고 벽, 밝은 오크 바닥, 베이지·오트밀 운동복. 얼굴은 보이지 않게.
- 번호별 자리 (`data-photo`): 1 빈 스튜디오(4:5) · 2 리포머 다리 뻗기 · 3 자세 교정(3:4) · 4 스프링 클로즈업(체험 예약, 컴퓨터 화면만) · 5 바렐 스트레칭 · 6–8 강사 · 9 라운지 · 10 커튼 빛(와이드)
- 파일 이름: `images/01.webp`, `images/01-sm.webp` … (1600px / 800px)
